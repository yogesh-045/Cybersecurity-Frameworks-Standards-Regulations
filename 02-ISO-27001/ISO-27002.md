# 🔐 ISO/IEC 27002:2022

## 📌 Overview

**ISO/IEC 27002** is an international standard that provides guidance for implementing and managing information-security controls.

### Simple Definition

> **ISO/IEC 27002 provides guidance on information-security controls that organizations can use to manage and reduce security risks.**

It is closely related to **ISO/IEC 27001**.

---

# 🧠 ISO 27001 vs ISO 27002

This is one of the most important concepts.

### ISO/IEC 27001

Focuses on:

> **Requirements for establishing and maintaining an ISMS.**

### ISO/IEC 27002

Focuses on:

> **Guidance for implementing information-security controls.**

### Simple Relationship

```text
ISO 27001
   ↓
ISMS Requirements
   ↓
Risk Assessment
   ↓
Determine Security Needs
   ↓
ISO 27002
   ↓
Control Guidance
   ↓
Implementation
```

---

# 🎯 Purpose of ISO 27002

ISO/IEC 27002 helps organizations:

* Understand security controls
* Implement appropriate controls
* Improve existing controls
* Reduce information-security risks
* Support ISO/IEC 27001 implementation
* Establish consistent security practices

---

# 📦 ISO 27002:2022 Control Structure

ISO/IEC 27002:2022 organizes controls into **four themes**.

```text
ISO 27002:2022
│
├── Organizational Controls
├── People Controls
├── Physical Controls
└── Technological Controls
```

There are **93 controls** in the 2022 edition.

# 4. Information Access Restriction

Access to information should follow the principle of least privilege.

### Principle of Least Privilege

> A user or process should receive only the permissions necessary to perform its authorized function.

# 🔗 ISO 27002 and NIST SP 800-53

Both provide extensive security-control guidance, but they are different publications with different structures and purposes.

| ISO 27002                         | NIST SP 800-53                              |
| --------------------------------- | ------------------------------------------- |
| ISO/IEC guidance                  | NIST control catalog                        |
| 93 controls in 2022 edition       | Much larger detailed control catalog        |
| Four themes                       | Control families                            |
| Supports ISO 27001 implementation | Supports security/privacy control selection |
| International standard guidance   | NIST publication                            |

# 📊 ISO 27001 vs ISO 27002

| Topic            | ISO 27001                   | ISO 27002                      |
| ---------------- | --------------------------- | ------------------------------ |
| Main purpose     | ISMS requirements           | Control guidance               |
| ISMS             | Core focus                  | Supports implementation        |
| Risk management  | Required                    | Supports risk treatment        |
| Annex A          | Reference control set       | Detailed control guidance      |
| Certification    | Yes                         | No standalone certification    |
| Controls         | Reference set               | Guidance on controls           |
| Primary audience | Management + security teams | Security/control practitioners |

# ❗ Common Misconceptions

## ❌ "ISO 27002 is a replacement for ISO 27001."

False.

They complement each other.

---

## ❌ "ISO 27002 certification is the same as ISO 27001 certification."

False.

ISO 27001 is the standard associated with ISMS certification.

---

## ❌ "Every ISO 27002 control must be implemented."

False.

Control selection should be driven by:

* Risk
* Business requirements
* Legal requirements
* Security objectives
* Organizational context

---

## ❌ "ISO 27002 guarantees cybersecurity."

False.

Controls reduce and manage risk; they do not guarantee zero incidents.

# ⭐ Key Takeaways

* ISO/IEC 27002 provides **information-security control guidance**.
* The current edition is **ISO/IEC 27002:2022**.
* The 2022 edition contains **93 controls**.
* Controls are grouped into four themes:

  * Organizational
  * People
  * Physical
  * Technological
* ISO 27002 complements ISO 27001.
* ISO 27001 focuses on the **ISMS**.
* ISO 27002 focuses on **control guidance**.
* Control implementation should be **risk-based**.
* Logging, monitoring, vulnerability management, access control, network security, cryptography, backup, and malware protection are important technological-control areas.
* ISO 27002 is particularly useful for understanding how high-level security requirements translate into practical controls.
